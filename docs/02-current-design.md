# 当前设想与候选架构

记录日期：2026-11-11。本文是研究设想档案，不是已实现算法的说明。

**状态：尚未实现、尚未训练、尚未开展机器人实验。不存在本文方案的成功率或性能结果。**

## 1. 用户当前想解决的问题

在一个明确限定的场景内，利用仿真强化学习，使机器人从需要慢速理解、探索和逐步控制，逐渐获得熟悉情形下无需反复推理的快速操作能力，并研究从仿真迁移到实物的高可靠执行。

用户的认知类比是：人第一次使用电脑时，需要理解屏幕反馈、手部移动与环境变化的关系；熟练之后，同样的操作可以直接、连贯地完成。这里的研究对象不是证明系统复制人脑，而是建立可测量的对应机制：

- 慢系统提供初期的场景理解、探索方向和直接控制能力。
- 快系统通过持续交互形成连贯动作与技能。
- 系统逐步减少不必要的慢思考，仍能处理尚未熟悉的状态。
- 新窗口或新对话不应丢失已经学会的操作经验；经验需要存在参数、检查点和持久存储中。

用户明确以类似 [SimpleVLA-RL](https://arxiv.org/abs/2509.09674) 的仿真在线强化学习作为整体训练过程，希望形成“一体的训练指引 → 成熟策略快速成型”的方法，**不把人工采集任务演示、再离线 BC 作为必经流程**。

## 2. 已明确的意图、仍需澄清的约束与助手提案

| 类别 | 当前记录 |
|---|---|
| 用户明确的目标 | 单场景，不优先考虑跨场景泛化；仿真在线 RL；无需事前人工任务示范；慢理解逐渐形成快速本能；最终面向 sim-to-real 高可靠操作。 |
| 用户给出的模块角色 | VLM 与直接控制代表初级场景理解；VLA 或类似快执行策略代表熟悉之后的本能行为。 |
| 用户给出的任务例子 | 用户举例包括 pick-and-place，以及 RoboDojo 一类更长程、更复杂任务；尚未指定先后顺序。先从固定 pick-and-place 起步是助手的实施建议。具体机器人、任务实例、传感器与 GPU 未确定。 |
| 用户最初的架构设想 | LSTM 或其他时序策略；gate 选择探索与快执行；也可能用一层 Transformer 学习决策器。 |
| 用户最初提出的扩展 | 精确采样场景；用仿真 RL 评分；边探索边训练；考虑 SuperMimic 式动力学预测器与 WAM 预测未来多步结果。 |
| 尚未明确的严格程度 | “无需采集数据”当前按无需人工任务示范理解；是否允许在线教师辅助损失、是否允许任务 SFT、是否要求完全随机初始化，仍需分别定义。 |
| 助手提出的候选 | hard gate 的联合 RL、RL + 在线知识转移、strict RL guided product-of-experts（下称 guided PoE）、语义上下文指导、可选恢复 option。 |
| 助手提出但用户未采纳为定案的内容 | 冻结约 7B 慢 VLM、小型快策略、具体 token 公式、模型规模和各项消融。它们是研究建议。 |

四个概念不能混写：

1. **零人工任务示范**：不人工录制该任务的动作数据；训练样本来自在线仿真交互。
2. **零任务 SFT**：不使用该任务的监督微调动作轨迹。
3. **只用 RL 训练目标**：不使用在线 BC、交叉熵、KL 等教师辅助目标。
4. **全随机冷启动**：没有通用 VLA、机器人数据或其他预训练技能。

这些约束不是一条逐项递增的线性层级，应分别声明是否满足。例如，零人工任务示范仍可能使用自动生成的任务 SFT；零任务 SFT 仍可能使用在线教师辅助损失；只用 RL 目标仍可能从已有任务 SFT 检查点初始化。使用冻结预训练 VLM/VLA 可以符合第一项，却不能被称为没有任何先验。RL 也会产生并使用大量数据，“无需人工采集”不等于“无数据”。

## 3. 总体闭环

建议把单次控制抽象为以下公共过程，具体融合机制另选：

```text
RGB / 深度 / 本体 / 历史 / 任务进度
                  │
             状态历史 h_k
                  │
          廉价的调用/技能决策器
             ┌────┴────┐
        不查询慢系统   查询慢系统
             │          │
          快策略     冻结 VLM → 局部目标/建议 → 固定适配器
             └────┬─────┘
              某种融合机制
                  │
        统一动作接口与执行控制器
                  │
                 仿真
                  │
        观测、奖励、终止、真实耗时
                  │
             在线 RL 更新
                  └─────────→ 快策略与决策器
```

这里的“廉价”意味着 gate 先使用现有感知特征判断是否值得查询。若每次先运行 VLM，再判断是否需要 VLM，就已经支付慢推理成本。

一体训练指共享在线交互循环、奖励与版本管理，不要求所有模块从第一步同时更新。冻结慢 VLM、先更新快策略与 gate，可以减少非平稳性。

## 4. 候选 A：原始 hard gate / options

在 chunk 或 option 边界，gate 选择 FAST 或 SLOW；可在后续研究中增加 RECOVER。两条路径使用同一物理动作接口。

- **FAST**：VLA 或小型策略产生连贯 action chunk。
- **SLOW**：VLM 产生子目标、局部 waypoint 或直接动作建议，经固定 interpreter/局部控制器执行。
- **RECOVER（可选）**：回撤、重观察、重新抓取或回到已知状态；不是现有已完成模块。

优点是实现容易解释、便于记录调用成本，也与 options 的持续时间结构一致。主要局限是：**慢分支执行时，独立快动作头通常没有对应的 on-policy actor 梯度**。共享视觉编码器受到训练，不等于快动作头已经学会慢动作。

因此，hard gate 是有效的控制权分配基线，但仅凭混合系统成功率上升，不能宣称慢能力已经内化到快策略。[Option-Critic](https://arxiv.org/abs/1609.05140) 提供选择与终止的形式化，并不自动完成知识转移。

## 5. 候选 B：RL + 在线知识转移

这条路线在同一个在线仿真循环中同时做两件事：

1. 环境回报训练快策略或混合策略。
2. 在学生实际访问的状态上，把经过验证或加权的慢指导写入快策略。

辅助目标可以是教师动作 NLL、明确分布之间的 KL/交叉熵，或适合所用连续动作策略的监督目标。它不要求事前人工演示集，也不要求先完成采集阶段再做离线训练。

其优势是传递机制明确；风险是错误教师会限制学生，固定过强的教师损失会阻止学生超过教师。需要退火、回报或优势筛选，并验证筛选器误差。

这是 [Kickstarting](https://arxiv.org/abs/1803.03835)、[RPD](https://arxiv.org/abs/2503.05833) 等工作的相关机制。它应准确称为 **RL + 在线知识转移**，不能声称全部参数更新都只来自 RL。

## 6. 候选 C：strict RL guided PoE

如果进一步要求快动作策略只由 RL 目标更新，助手提出的一个待验证候选是：

> 慢系统不替学生执行，而是把语义建议转换为可归一化的动作先验；最终动作始终从包含快策略 logits 的受引导分布采样。

以 SimpleVLA-RL 的离散动作 bins 为例：

$$
q_{\theta,j}(b\mid h_k,z_k,m_k)
=\operatorname{softmax}_b
\left[
\ell^F_{\theta,j}(b\mid h_k)/T
+\alpha_{m_k}\log p^S_j(b\mid h_k,z_k)
\right].
$$

- $j$：chunk 中某个动作标量的位置。
- $b$：离散 bin。
- $\ell^F$：快策略自身 logits。
- $z_k$：慢 VLM 提供的局部目标或建议。
- $p^S$：由固定适配器构造的动作先验。
- $\alpha_0=0$：无指导模式；$\alpha_1>0$：有指导模式。

两种模式的动作都依赖快参数，所以指导阶段也能给快策略奖励加权的梯度。具体 likelihood 与梯度见 [训练目标](03-training-objectives.md)。

这条路线借鉴分布融合思想，但它不是 SimpleVLA-RL、BCF 或 MCP 已经验证的完整方法。特别是：

- 强先验可能让分布近确定，削弱探索与有效梯度。
- 快策略可能只学会“修正先验”，撤掉先验后失败。
- 独立 scalar prior 可能破坏跨维度、跨时间的动作相关性。
- 两个相冲突的高斯/单峰技能经 PoE 也可能产生危险中间动作。
- VLM 的自报置信度不能直接当作校准后的先验方差。

必须持续进行无指导交互与 fast-only 评估，才能检验“本能成熟”。

## 7. 其他融合分支：记录但不作为定案

| 分支 | 方法与条件 | 为什么未选定 |
|---|---|---|
| 可选语义上下文 | gate 决定是否更新建议，快策略始终从 $\pi_F(a\mid h,z,\mathrm{age}(z))$ 采样；训练中保留 $z=\varnothing$ 分支。 | 控制来源清楚，但仍不能保证建议撤去后能力自动保留。 |
| 边缘 mixture | $\pi(a)=g_F\pi_F(a)+g_S\pi_S(a)$，使用正确的边缘 likelihood。 | 必须能计算两分支动作密度；若 mode 本身影响成本、等待或转移，不能无条件把 mode 边缘化。 |
| 残差控制 | $u=u_{base}+\delta u_F$。 | 适合细调，但快残差通常仍依赖基础控制器，不能自动独立。 |
| 价值/critic 迁移 | 所有真实转移训练 critic，快 actor 优化共同 Q。 | 可利用更多交互，但会改变为 off-policy actor-critic 或混合算法，不能声称原始 GRPO 完全不变。 |

## 8. 动作接口：action trunk 与位移不属于同一层级

action trunk / action expert 是“用什么网络产生动作”；末端位移、关节角、速度、力矩是“动作表示什么”。可以由 action expert 输出位移 chunk。

单臂参考接口可以是：

$$
u_t=[\Delta p_t^B,\Delta\theta_t^B,g_t]\in\mathbb R^7.
$$

这里 $B$ 为基座坐标系，旋转增量用旋转向量；例如：

$$
p^{ref}=p+\Delta p^B,\qquad
R^{ref}=\exp([\Delta\theta^B]_\times)R.
$$

这只是接口示例。复用已有 VLA 必须遵守其动作归一化、坐标系、控制周期与夹爪语义。RoboTwin 等双臂任务的维度不能一律写成 7。

慢系统的 waypoint、快策略的 action chunk 和恢复控制器，最终必须对应同一执行器约定。连续动作经过约束过滤后发生变化时，要同时记录原始采样动作与实际发送命令；策略 likelihood 属于原始随机变量，环境反馈属于实际执行闭环。不能把事后实际位移倒填成原策略的采样动作。

## 9. 长程记忆与技能持久化

“换窗口忘了”至少包含三种不同问题：

- **运行时历史丢失**：对话文本、RNN 隐状态、当前缓存。
- **任务进度丢失**：哪些子任务已完成、物体状态是否改变、下一步先决条件。
- **技能遗忘**：参数更新后旧技能、恢复行为或困难状态的能力退化。

推荐研究时分别记录，不把一个 LSTM 当作全部解决方案：

| 存储 | 作用 |
|---|---|
| 策略检查点 | 保存已学动作技能、归一化参数和版本。 |
| rollout/事件档案 | 保存成功、失败、接管、恢复、传感异常与行为来源。 |
| 任务图与对象状态 | 显式表示长程任务的依赖、后置条件与完成集合。 |
| 短期时序状态 | 估计部分可观测性下的接触、滑移与运动历史。 |
| 建议缓存 | 保存慢建议内容、生成时刻、来源与有效范围。 |

新对话不会擦除已落盘的模型权重。任务图推进应由后置条件验证，而不是仅凭一次语言判断或“动作发出过”。

## 10. WAM / SuperMimic 式动力学：可选，而非当前必需

用户希望探索同步学习多步结果预测器，用预测奖励指导探索，并可能让快策略通过想象结果更快训练。这仍保留为重要分支。

建议最先检验的预测对象不是视频美观度，而是任务相关后果：物体位姿、夹持状态、接触事件、失败概率与候选动作回报排序。一个局部预测器可以学习：

$$
f_{\omega_i}(b_t,u_t^{exec},\Delta t)
\rightarrow(\hat b_{t+1},\hat r_t,\hat p_{fail},\hat x_{t+1}).
$$

$u^{exec}$ 是经过过滤后实际发送给低层控制器的命令，不是事后观察到的位移。短期 rollout、ensemble 分歧、重锚到实测状态可以作为控制模型误差的候选措施，但 ensemble 分歧不是已校准的失败概率。

若通过冻结世界模型反向优化策略，应冻结模型参数、保留其对动作和状态的 Jacobian；detach 全部模型输出会切断想象回报梯度。视觉接触任务中的梯度正确性必须独立检验。SuperMimic 的动作跟踪结果不能直接充当本方案视觉操纵的证据。

首轮实验可不加入 WAM，先确认融合机制能加速独立快策略成长，再检验 WAM 的增量价值。

## 11. 模型规模与结构：尚无定案

最新实现候选优先保留 SimpleVLA-RL 的快 VLA 与离散动作管线，避免同时更换骨干网络和训练目标。此前讨论过的“小型快策略”是另一条规模实验分支，不能与基线混为一谈。

| 模块 | 曾提出的参考起点 | 当前状态 |
|---|---|---|
| 慢 VLM | 比较 3–8B，以冻结约 7B 模型起步。 | 助手建议，模型未选。 |
| 快策略主基线 | 复用 SimpleVLA-RL 对应 VLA、256-bin 动作与 action chunking。 | 参考实现方向，未接入。 |
| 小型快策略分支 | 共享双相机 ResNet-18、GRU-256、宽 256 的 8 层动作 Transformer；先前估计快路径约 21–22M 参数。 | 非已实现架构；参数量需以代码统计，不是最优规模结论。 |
| Gate | 廉价特征输入的小 MLP 或时序分类/策略头。 | LSTM/Transformer/MLP 均未定案。 |
| 动力学预测器 | 结构化短期模型、ensemble；大型视频 WAM 作为后续比较。 | 可选扩展。 |

## 12. sim-to-real 与“100%”的研究表达

保留用户的追求：在固定场景中达到仿真到实物的 100% 成功率。实现与报告时必须进一步声明初态、扰动、时间、恢复次数、人工接管和测试分布。

固定测试集全成功、分布成功率的统计下界、物理系统任何情况下永不失败，是不同命题。有限测试不能证明第三个命题。固定场景仍存在摩擦、遮挡、标定、延迟、抓取偏差和接触变化，不能将不追求跨场景泛化解释为不需要场景内稳健性。

精确场景几何之外，还需研究动力学辨识、延迟模拟、控制频率、相机年龄、执行误差与恢复策略。安全约束过滤器可作为共享执行层候选，但局部安全不等于任务必定完成。

本档案记录目标与研究问题，不宣称已经获得仿真或实物的 100% 结果。

## 13. 与现有研究的关系

- [Expert Iteration](https://arxiv.org/abs/1705.08439)：昂贵搜索改善快网络，快网络再引导搜索；思想上对应“思考摊销为直觉”，但包含监督学习。
- [Kickstarting](https://arxiv.org/abs/1803.03835)：学生在线 RL 与教师分布辅助同时进行。
- [BCF](https://arxiv.org/abs/2107.09822)：控制先验与 RL 分布融合，相关机器人先例；VLM 先验的可靠性需另证。
- [MCP](https://arxiv.org/abs/1905.09808)：多个技能通过分布乘积组合；不等于零示范慢快共同成长。
- [Option-Critic](https://arxiv.org/abs/1609.05140)：学习技能内部策略、选择与终止。
- [SimpleVLA-RL](https://arxiv.org/abs/2509.09674)：提供参考仿真在线 RL 管线，但论文使用任务 SFT 初始化。

研究贡献不能只写“双系统”。待验证的核心是：**在无需人工任务示范的在线仿真 RL 中，慢语义指导能否改善初始成功探索，并更快形成撤去指导后仍可靠的快策略。**
