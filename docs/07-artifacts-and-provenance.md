## 原始消息的导出范围

records/discussion.raw.json 收录本聊天能够读取的两个已完成研究轮次，按原顺序保存 3 条用户研究消息、1 条助手澄清请求和 2 条助手最终研究回答，共 6 条消息。文本保留原貌；records/discussion.zh-CN.md 仅添加角色和轮次标题。

用户的一次补充答复在原消息中使用异步问答标记，原样保存。原文含应用专有引用语法、下载指令和 /data/ 本地文件地址，这些显示语法在 GitHub 上未必可点击；这里的 README 提供仓库内链接。

不包含系统提示、隐藏推理、工具操作日志、账号资料、凭证或其他聊天内容。当前“上传 GitHub”的操作轮次不计入研究原文；其结果由此档案结构记录。

## 图稿生成源文件

archive/authoring-source/v1-deck.mjs 和 v2-figures.mjs 是原始作者脚本快照。保留原来的输出路径、字体与制作环境依赖，未伪装为可直接安装的研究代码。它们依赖原环境提供的 @oai/artifact-tool 和图稿验证工具；在其他电脑直接运行需要调整这些路径并提供相应运行时。

可编辑交付物是 PPTX 本身，不要求读者运行脚本。scripts/verify_archive.py 是独立的 Python 标准库检查器，用于验证本地文件完整性、PPTX 结构和已生成的 SHA-256 清单。

## 完整性与状态

MANIFEST.sha256 记录归档内容的 SHA-256（不包括清单自身）。运行 python3 scripts/verify_archive.py 检查文件、ZIP/PPTX 完整性与核心链接。任何后续改动都应重新生成清单。

研究中的数学公式、网络规模、训练配置、奖励权重与评测数量是实验提案；没有训练日志、跑分、机器人视频或成功率结果随此次归档产生。
