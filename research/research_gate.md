# 慢思考—快技能路由、持续学习与可靠性：研究备忘

核查日期：2026-11-11。下文区分「论文报告」「由论文支持的设计推论」「本文建议」，后两者不是已有论文的实验结论。

## 1. 结论与最重要的纠偏

这个构想合理，但真正有文献基础的表述是：**把昂贵的规划/搜索结果持续蒸馏成任务专用闭环技能，以不确定度、任务价值与控制成本决定何时调用规划，并用独立的安全控制与恢复机制约束两者。** 它是分层强化学习、主动模仿学习、模型预测控制、持续学习的组合，不需要依赖「模拟人脑」这一未经验证的生物学解释。

- 经验持久化不由上下文窗口负责。上下文、LSTM/GRU 隐状态是运行时工作记忆；长期经验要存进回放库、技能参数、校准集、环境参数后验和检查点。换窗口不会抹去已保存的权重；只保存在对话文本里的经验才会失效。
- 「见过画面」不是快策略可胜任的充分条件。相同 RGB 画面可能有不同接触力、物体速度、夹持滑移或相机延迟。路由应看成功概率/价值与不确定度，使用状态历史或信念状态。
- 规划慢、控制快，不等于「探索」与「执行」二选一。慢系统可在熟悉但高风险的状态重新规划；快策略也可进行受约束探索。建议把 computation mode、policy competence、exploration budget 分开建模。
- 对固定任务，VLM 未必需要常驻。应比较「视觉/几何估计 + 经典规划/阻抗控制 + 小策略」；若纯几何基线更稳，大模型的价值主要在初始技能引导、异常解释与生成候选方案。
- 不能由任何有限次试验建立无条件 100% 成功率。可以争取固定测试分布下 100% 的观察成功率，并报告置信下界；或者在明确的初始集合、扰动界、感知误差界和动力学假设下证明条件性的 reach-avoid 保证。

## 3. 把用户的 gate 设想写成可训练对象

### 3.1 统一动作语义

底层物理命令只有一个标准，例如 a_t = [Δp_x, Δp_y, Δp_z, Δr_x, Δr_y, Δr_z, g] ∈ R^7，带确定的坐标系、单位、最大值和控制周期。VLA 的 action expert 可以直接产生这种动作块；「VLA」和「位移」不是互斥的动作空间。

推荐先只定义三个 option：

- o_F：轻量闭环快速策略，每次预测 H 个低层动作，只执行头 K 个再观测。
- o_S：慢 VLM 提供候选子目标/约束；MPC/运动规划给出同一 R^7 格式的动作块，再闭环执行。
- o_R：恢复/重新观测/安全停机；必须有明确允许的起始集合和终止条件。

如果另有一个冻结的外部 VLA 专家，可以把它作为第四个 option；不要因为它叫 VLA 就另造一个物理 action 类型。

令 b_t = Enc(o_{t-L:t}, q, qdot, wrench, a_{t-L:t-1}, mode, goal, age) 表示观测历史与内在模式的近似信念状态。若选 GRU/LSTM，隐藏状态属于 b_t；包括上个 option、执行进度、指令年龄，避免同一输入实为不同执行阶段。

### 3.2 门控目标：成功优先，计算/速度其次

可先采用工程上可解释的约束式路由：

O_adm(b) = {o: safety_mask(b,o)=1 且 p_L(success within T | b,o) ≥ 1−ε}。

在 O_adm 非空时选择估计完成时间或代价最小的 option；若为空，优先运行有保障的重新观测/恢复，否则安全停止。这里 p_L 是经过独立数据校准的保守估计，神经网络给出的单个数值不等于已被证明的下界。

更一般地，J = E[success − λ_time × wall_clock − λ_energy × energy − λ_switch × switches]，subject to P(safety violation) ≤ δ。若把时间和成功直接加权，系统可能为省时间接受更多失败；若用户把可靠性设为第一目标，应用约束式/词典序优化，先满足可验证风险门槛，再优化速度。

「慢」所花推理时间不能被忽略。计算期间机器人持有安全参考或者执行上一个已验证的短动作段，并持续观测；新计划必须检查时间戳、状态变化和有效区间，过期即拒绝。

### 3.3 SMDP critic 与 termination 的具体计算

从回放中取 (b_t, o_t, τ, R_t^(τ), b_{t+τ}, done, policy_version)，其中

R_t^(τ) = Σ_{j=0}^{τ−1} γ^j r_{t+j}，γ 是每个物理控制周期的折扣，而不是每调用一次 option 的折扣。

固定各 option 或短时间冻结其版本时，可以使用双 Q 的目标：

y = R_t^(τ) + (1−done) γ^τ Q_target(b', argmax_o Q_online(b',o))；

L_Q = E[(Q_online(b,o) − stopgrad(y))²]。

风险、成功率和时间建议使用独立预测头，不要从一个混合 Q 值反推所有语义。终止时刻决策用 V(b)=Σ_o g(o|b)Q(b,o)。继续 option 的价值为

U(b',o) = (1−β_o(b'))Q(b',o) + β_o(b')V(b')。

Option-Critic 的终止梯度核心是 −E[∇β_o(b') × (Q(b',o)−V(b'))]：当前 option 比切换差则增加终止概率。可加最短持续时间、最大时长、切换迟滞及小终止正则；安全异常可以强制提前终止。先固定 chunk 边界终止，比一开始端到端学习 β 更易诊断。

门控若独立 actor-critic 学习，可用 L_gate = −E[log g(o|b) × stopgrad(y−V(b))] − α H(g)，在仿真训练中保留探索，在实物评估中关闭随机路由。这个等式是一般 actor-critic 实现建议，不等于直接套用完整 Option-Critic 理论即可保证神经网络收敛。

### 3.4 推荐起步规模（工程起点，不是论文结论）

- gate 输入：共享视觉/状态 latent 256 维 + 每个专家的成功、分歧、预测时间/风险、当前 option/进度等，约 280–320 维。
- gate：MLP 320→256→128→3，约 0.12 M 参数；终止头 128→3 或每个 option 一个 sigmoid。低维状态已近 Markov 时不需要 transformer。
- 如观测部分可见：额外 GRU 256、输入 256，约 0.395 M 参数；由其输出供 gate。控制环应实测端到端延迟。
- 价值/风险集成：5 个独立初始化的 320→256→256→3 MLP，合计约 0.74 M 参数；成功和时间可用不同 heads，但共享 backbone 时不确定度并非完全独立。
- 对 gate 用 Transformer 的理由只能是历史中的长程依赖，而不是「更强所以应该用」；如果没有消融证明收益，会引入更多数据和时延成本。

## 4. 为什么不能调用 VLA 就 +0.1

如果任务奖励是成功 +1，给每次调用 VLA +0.1 会造成三个问题：

1. 两条到达同一结果的轨迹，仅因为多调用 VLA 就拿到不同回报，优化目标已从成功/效率改为「多调用」。
2. 可出现反复调用但不推进任务的循环；折扣只能限制总回报，不消除偏好错误。
3. 该奖金不能告诉 gate 在哪个状态调用 VLA 真正改变了结果；甚至可能掩盖 VLA 失败。

如果确实有计算偏好，应使用与实测代价相联系的惩罚，例如 r = r_task − c_ms × milliseconds − c_switch，而非奖励品牌/架构。训练初期为保证两条路径都有数据，可以使用采样配额、ε-greedy、option entropy 或仅在仿真中的探索奖励；最终评估回报应回到真实目标。

如需保持原最优策略的稠密塑形，原始 MDP 可用 F(s,s')=γ Φ(s')−Φ(s)；option 层相应为 γ^τ Φ(s')−Φ(s)，同时正确处理终止/吸收态的势函数。简单欧氏距离在接触任务常会误导，应加入任务阶段或几何可行性，且不能把潜在错误当作成功标准。

## 5. 如何预测「选择 VLA 这一策略」的结果

不能把一个抽象的 VLA ID 丢给只学过 (state, primitive_action) 的一步动力学模型，就声称可以预测它的所有动作。两个可行办法：

**办法 A：真实地展开内部策略。** 在每个预测步用冻结版本 π_o 产生 a_hat_j~π_o(·|b_hat_j)，再用 D_k(z_hat_j,a_hat_j) 推到下个 latent；同时预测奖励、接触和终止。对多个策略采样与多个模型做 rollouts，得到返回分布。option 是状态反馈策略，其未来动作必须在未来预测状态上重新生成；只把第一帧动作块开环重播仅近似短期行为。

**办法 B：直接学习 option 模型。** M_o(b) 预测 (b',R,τ,success) 的联合分布，用完整 option 执行日志监督。它天然表达「执行这个策略后会怎样」，但当 option 参数更新时模型会过期，必须冻结一段更新、记录 policy_version 或重新收集数据。

模型不确定度大的状态，模型预测只用于提出候选，不用它代替真实评价。想象轨迹应标记 synthetic、限制 rollout 长度和占比，并与实测回报分别存储；否则 gate 会利用世界模型的误差。

## 6. 门控的反事实配对实验：比单纯在线分类更干净

门控常见混杂：它只在困难状态调用慢系统，于是慢系统的平均成功率更低，不能由此判断慢系统无用。建议仿真中做同初态分叉实验：

1. 从快策略的真实占用分布与失败前沿采样 b 和完整 simulator state；保留观测历史、随机化动力学参数 θ 和 contact state。
2. 克隆同一仿真状态，分别运行 o_F、o_S（以及有意义的 o_R），使用相同未来扰动样本/随机种子，重复 M 次；共同随机数用于降低差值方差。
3. 计算每个 option 的 R^(τ)+γ^τ V(b')，并记录真实成功、碰撞、接触峰值、计算时长、继续执行状态。不同持续时间不能仅比较本段累计 reward。
4. 用 ΔJ=J_F−J_S 及置信区间训练排序或成功预测。差值小、噪声大或两者都失败的样本，标为不确定/需恢复，不强制硬标签。
5. gate 先学监督排序，再用 SMDP RL 微调；保留一份未参与训练的参数/初态组合做校准。
6. 实物没有可同时观测的两个反事实，只能用受控重复初态/配对随机试验近似验证。仿真中的反事实结论必须再检查现实参数下是否成立。

这些配对标签是推荐实验设计，不是声称已由上表某篇论文完整验证的算法。

## 7. 持续学习：慢系统如何逐渐退出

建议交替循环而非所有模块从第 0 天共同漂移：

① 标定环境、定义任务成功与失败 → ② 慢系统/人类/规划器收集可执行示范 → ③ BC 训练快策略 → ④ 快策略运行，慢系统或人类在失败前接管，DAgger 聚合修正样本 → ⑤ 固定编码器/专家短周期训练动力学与 critic → ⑥ 配对 rollout 训练 gate → ⑦ 小步 RL 微调 → ⑧ 用独立回归集验证后更新部署版本。

数据必须保留首次成功、困难初态、接触前后、失败、恢复、近失误；只保留成功数据会使风险模型看不到负例。每份样本记时间戳、相机/机器人标定版本、sim 参数、action 单位、policy_version、是否被人工介入。用于正式成功率评估的试验必须无人工纠正，或者把干预计入失败；否则无法解释自治成功率。

随着快策略扩大胜任区，慢调用比例自然下降；应该测量「慢调用率 vs 同等成功率下的周期时间」，不应预设训练越久调用越少就一定越好。遗忘检验至少同时看固定旧状态回归集、新失败集、恢复集。

## 8. 「100%」的三个不同命题

### A. 测试观察值 100%

在固定且独立同分布的 n 次无干预试验中全成功，观察成功率是 100%。若做**单侧 95% 的精确二项置信下界**，则 p_L=0.05^(1/n)。依据为 Clopper–Pearson 精确二项构造；[NIST 官方说明](https://itl.nist.gov/div898/software/dataplot/refman2/auxillar/exacbino.htm)。这是 frequentist 覆盖保证，不是「观察数据后真实 p 有 95% 概率大于下界」的贝叶斯解释。

| 独立试验全部成功 | 真实成功率的单侧 95% 下界 |
|---:|---:|
| 10/10 | 74.11% |
| 100/100 | 97.05% |
| 299/299 | ≥99% |
| 1,000/1,000 | 99.7009% |
| 2,995/2,995 | ≥99.9% |
| 29,956/29,956 | ≥99.99% |

n≥ceil(log(0.05)/log(p_target))。相关重复、同一次标定、挑选好看的初态、在测试集上反复改模型均会削弱这个解释。若持续看结果并择时停止、同时测试多任务/多模型，需要预先固定试验或用序贯有效的统计程序，不能原样套固定 n 界。

HIL-SERL Table 1a 中 100/100 是「A」的实例，不是下述「B」。

### B. 有假设的形式保证

先规定闭集 X_0、目标 G、安全集合 S、扰动 w∈W、感知误差 e∈E、执行/推理最大时延和模型不确定界，再证明：∀x_0∈X_0，∀允许扰动序列，闭环轨迹都保持在 S 并在 T 内进入 G。

CBF 可帮助证明留在 S；要保证到达 G 还需适当的 CLF/有限时间收敛/鲁棒 MPC 可行性或 reach-avoid 证明。CBF-QP 求解失败、执行器饱和、离散采样、接触模型突变和状态估计误差均必须进入假设，否则保证不完整。安全停机只是安全保持，不算完成任务。

### C. 无条件真实物理世界永不失败

若包含未界定硬件故障、断电、未知外力、物体破损或感知失效，不能由学习系统或有限验证建立这个命题。研究中应把目标改为「在声明的工作包络内，零观察失败 + 高置信统计界 + 可验证的局部安全/恢复保证」，同时把包络外拒绝执行计入覆盖率而不是隐藏在成功率里。

## 9. 值得优先测的消融与失败诊断

- 小快策略 + 阻抗控制 vs 单独大 VLA：检验大模型是否真有必要。
- 恒快、恒慢、启发式 gate、监督配对 gate、SMDP gate：在相同任务预算下比较成功率和周期时间。
- 有/无世界模型；有/无 ensemble pessimism：检验收益是否来自规划，还是模型错误被利用。
- 单帧 vs 历史/GRU；相同画面、不同隐藏接触状态的专门压力测试。
- sim-only vs 少量实物校准 vs 实物 RL/人工接管：定位 sim-to-real gap。
- 完整系统 vs 去掉恢复/独立成功检测：判断高成功率来自策略能力、恢复次数还是判定漏洞。
- 每次记录自治首次尝试成功、允许自动恢复的最终成功、拒绝执行率、人工接管率、超时率，三类成功定义不可混用。
- 按初态/摩擦/时延区间分层报告最差组成功率；平均值会遮蔽一个小但稳定失败的子区域。

## 10. 最有发表价值的潜在贡献

单纯「LLM + 小策略 + gate + 世界模型」组合本身新颖性有限。更有价值的是一个可检验命题：**在固定场景的受控工作包络内，以实物校准风险为约束，通过同状态反事实 option 评估和在线蒸馏，在保持规定成功率下界的同时系统性降低慢推理调用率与任务周期。** 关键贡献可落在路由校准、失配感知 option 模型、恢复闭包和 sim-to-real 可靠性验证，而非神经网络结构堆叠。
