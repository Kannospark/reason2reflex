# 独立架构审查：固定场景的慢规划、快执行与世界模型

本文是为主报告准备的设计稿。文中数值是可以开始工程实验的一组配置，不是论文已经验证的最优配置，不是对延迟、成功率的承诺。假设单个 7 自由度机械臂、平行夹爪、固定桌面、一个刚性操作对象、一个目标区域；不涉及柔性物体、双臂、高速抛接与精密装配。任务、硬件、接触精度未知时，不存在科学上可信的唯一模块大小。

## 1. 对原设想最重要的五个修改

1. **“VLA 的 action trunk”和“位移”不是同层概念。** trunk 是产生动作的网络组件，位移是动作表示。快策略、慢策略最后都应使用相同的物理动作接口；gate 选择的是控制选项，而不是选择单位。慢系统可以给出目标、约束和候选轨迹，快策略与规划控制器分别将它们落到原子动作。
2. **“见过的画面”不能作为可靠性的充分条件。** 同一图像可能对应不同速度、接触力、摩擦、延迟与夹爪滑动状态。gate 需要历史信念、模型不确定性、进展和力觉；图像相似度只是一个特征。
3. **“在线学习”至少分成三件事。** 实时更新状态/隐变量，持久化经验到数据库，更新网络参数。第一项可以每帧做；第二项可以每回合做；第三项建议先做影子训练、固定版本评估再部署，不应在一次接触操作中无检验地改权重。
4. **world model 给的是预测结果和有误差的价值估计，不是提前拿到真实奖励。** 仿真器内的真实执行奖励、真实机器日志奖励、学习模型的想象奖励必须分字段记录，后者不应自我验证前者。
5. **把“100%”变成有边界的可靠性问题。** 即使场景固定，也有隐状态与硬件随机性；有限测试无法证实真实成功概率等于 1。可研究在声明的操作域内、给定置信度与拒绝率下的失败率上界。若 0 次失败且样本独立同分布，一侧 95% 的成功率下界为 `0.05^(1/n)`：300 次约 99.006%，3,000 次约 99.900%，30,000 次约 99.990%；这些数字不是处理漂移与相关性的保证。

## 2. 推荐的信息流和控制语义

`相机/本体/力觉 → 时间同步与标定 → 信念状态 b_t → 可靠性 gate`

gate 选择三个选项：

- **FAST**：调用已训练的目标条件动作 chunk 策略，在每个新观测后重规划。
- **PLAN**：慢 VLM 提议结构化子目标和约束；采样规划器在已校准的物理仿真器或短时世界模型中评价候选；选择可行候选，再由同一低层控制器执行。
- **RECOVER / REJECT**：保持、退回最近的安全状态、重定位、重新观测，或停止本次尝试。部署时所有选项的约束检查都失败，不能强迫在两个不可靠选项中选一个。

“慢 VLM 发现新场景”只是解释性比喻。落地时它应表现为：fast 预测的风险较高、价值差距不足、任务进展停滞、环境估计不一致等可测信号触发 PLAN。低风险、验证过的区域才放行 FAST。

慢计算期间继续运行经过验证的 hold/impedance 控制器；不能把几秒之前的动作 chunk 当作新命令发送。每个候选都携带 `observation_timestamp, policy_version, calibration_version, goal_id, valid_until`。输出到达后重新检查当前状态；如果超过有效期或误差阈值，则丢弃并重算。

## 3. 统一动作接口

在 20 Hz 的策略时钟下，动作定义为

`u_t = [Δp_x, Δp_y, Δp_z, Δω_x, Δω_y, Δω_z, w*] ∈ R^7`。

前三项是米，后三项是弧度旋转向量，最后是夹爪目标宽度（米）。本稿约定平移增量在机器人基座坐标系表达，旋转增量左乘；必须在数据、模拟器和实际控制器保持一致：

`p*_(t+1)=p_t+Δp_t`，`R*_(t+1)=Exp([Δω_t]×) R_t`。

这是 `R^3 × SO(3)` 的局部更新约定；如果实现采用真正的 SE(3) twist 指数映射，则同时使用 `T*=Exp(ξ^)T` 中的平移 Jacobian，不能把两种约定混用。所有策略训练使用归一化动作，但写入控制器前恢复物理单位。

起步时示例上限为每策略步 2 mm 平移、1° 旋转；20 Hz 时分别约 4 cm/s 与 20°/s。它们只是保守实验初值，实际应由机器人、负载、碰撞距离和接触任务规定。快速输送可以增大，插装接触需更小并加入力限幅。

快策略输出 `U_t ∈ R^(16×7)`，即未来 0.8 s 的候选动作序列；**默认只执行第一个 50 ms 的动作，再取新观测**。chunk 提供连续性，不等于开环执行 0.8 s。如果硬件推理只能 10 Hz，就执行前 2 个动作，并把延迟作为训练域的一部分。动作 trunk 可用 ACT/CVAE、diffusion 或 flow-matching，接口不变。ACT 的原研究支持 chunk 化模仿学习；其具体任务结果不能直接外推到本任务。[ACT 原论文](https://arxiv.org/abs/2304.13705)

若已有 VLA，它的动作专家可以替换本稿 fast decoder，只要通过 adapter 明确坐标系、尺度、夹爪语义和频率。**不要把独立的位移和 VLA 输出在接触时直接线性平均**：不同模式的平均动作可能对应无效抓取方向。应该在选项或轨迹层选择；若做 residual control，需定义有界残差 `u=u_base+αδu` 并单独验证。[Residual RL 原论文](https://arxiv.org/abs/1812.03201)

## 4. 一套可以开工的数值规格

### 4.1 观测与信念状态

两个同步相机（固定相机 + 腕部相机），RGB 224×224、深度与标定信息，30 Hz；策略以 20 Hz 使用最新完整观测。机器人本体与力觉采样建议 250–1,000 Hz，重采样到策略时钟。以不同频率输入时保留时间戳和 age，而不是假设同步。

结构化状态 `x_t ∈ R^48` 的一种分解：关节角 7、角速度 7、末端位置 3、四元数 4、夹爪宽度 1、六维腕力 6、物体位姿 7、目标位姿 7、物体速度 6，总计 48。四元数需归一化并处理双覆盖。必须从实际可用传感器估计这些量；模拟器真值只能用于 critic、标注和评估，不能悄悄供部署 actor 使用。若实际不测物体速度，改用差分滤波或历史估计，并在输入里标记置信度。

视觉编码使用共享权重 ResNet-18 去掉分类头，两张 RGB 各得到 512 维向量。深度用于对象位姿/碰撞几何估计，在这个预算中不另增视觉 backbone。视觉编码器约 11.2M 参数。`e_t=MLP_(1072→256)([v_fixed,v_wrist,x_t])`；`b_t=GRU_256(e_t,b_(t−1))`。MLP+GRU 约 0.67M 参数。GRU 是部分可观测信念近似，不是物理状态完备性的证明。

让 `b_t` 至少能够解码任务相关几何、速度和接触模式；用状态解码辅助损失或固定视觉特征目标避免潜变量塌缩。先训练后冻结 encoder/GRU，给第一版策略与世界模型稳定的表示。后续若联合训练，使用独立的 target/EMA encoder 并明确 stop-gradient，否则模型和标签一起漂移。

### 4.2 快策略

`π_θ(U_t | b_t,g_t)`：4 层 Transformer decoder，hidden 256，8 个 attention head，FFN 1024，16 个可学习 chunk query，输出 16×7。条件 token 为 `b_t` 和投影后的 `g_t∈R^32`。推理 decoder 约 4.2M 参数；可增加 2 层、hidden 256 的 CVAE posterior encoder 与 32 维 latent，训练时额外约 1.6M，部署可移除 posterior encoder。数据极少且动作单峰时，先用确定性 chunk BC 做更简单的 baseline，再验证多模态生成是否必要。

目标 `g_t` 是固定 schema（32 维或结构化 token），包含技能 ID、对象/末端子目标位姿、位置/姿态容差、接触模式、力界限、截止时间等。固定任务中 instruction 可以是固定 embedding；不必每个控制步重新调用语言模型。

20 Hz 是部署目标，**不是根据参数量推出的性能保证**。要求把相机传输、编码、policy、shield 和通信的 p95/p99 总延迟一起测量，超过 50 ms 就降低频率、减少模型或把推理放到独立设备。

### 4.3 慢系统

起步用冻结的 **4B–8B 级预训练 VLM**，只在事件触发时运行，不从零训练一个“脑”。4B/8B 是实验档位，不意味着大模型必然更会控制。显存按 checkpoint 实测：仅 BF16 权重约 8/16 GB，尚未算视觉 encoder、KV cache、框架开销与其他模块；量化需要重新评价输出和延迟。24 GB 设备优先试 4B 级；8B 级适合更大显存或独立推理卡。

VLM 输入最近 4–8 帧、可读状态摘要、失败记忆和技能库；输出 2–8 个**结构化子目标候选**（先验、约束、可解释理由可选），不让自然语言直接写关节力矩。候选先经 schema / reachable / collision 检查，再由规划器评价。VLM 是候选生成器而非真实性裁判。初版使用 4 个候选，每个 2 s 的物理模拟或短时模型评估；实际耗时需要实测，规划时钟可以是 0.2–1 Hz，不能承诺所有硬件都达到。

VLM 经验的“窗口刷新”不是必须失忆：持久化 `状态簇 → 子目标/技能/结果/失败原因/版本` 到日志和检索库；操作熟练度通过 fast 权重或技能参数保留。上下文记忆、GRU 隐状态与网络权重是不同时间尺度的记忆。

### 4.4 动作条件世界模型（WAM）

本稿把 WAM 明确定义为 action-conditioned dynamics model，不把它当作某篇同名论文的默认结构。初版不用视频生成：5 个独立 bootstrap 成员，各是 `MLP_(264→512→512→515)`。输入 `b_t(256)+u_exec,t(7)+Δt(1)`；输出下个 belief 的均值 256、对数方差 256、预测奖励 1、终止 logit 1、unsafe/contact-violation logit 1。每个约 0.66M，总计约 3.31M；加共享状态 decoder `256→256→48`，约 0.08M，总约 3.4M。

模型预测 `Δb` 而不是绝对 `b` 可作为可比较变体。快策略只依赖模型能够预测的 belief 和目标，因此 rollout 时无需生成像素再喂视觉 encoder。shield 需要的结构化状态用 `D(b)→x` 解码；这仍会有模型误差，不能据此把想象中的 shield 当作现实安全证明。接触切换、遮挡和硬件故障应提升不确定性或直接拒绝。

如果高保真模拟器的 2 s rollout 已经比学习模型足够快，**先用模拟器当 oracle planner**。WAM 的增益应在相同预算下证明，而不是为了架构完整而强行加入。

### 4.5 Gate 与价值/风险

gate MLP 输入约 272 维（`b256 + 不确定性/风险/新颖度8 + 前一选项onehot3 + 进展3 + 时效2`），结构 `272→256→128→3`，约 0.10M 参数。两个 Q 头可用 `291→256→256→1`（belief256+goal32+optiononehot3），合计约 0.28M。独立 success/failure 与 calibration 头可以再加不到 0.5M。gate 整组控制在 1M 以内足够作为起点；LSTM 或小 Transformer 不是分类必须条件，已有 GRU belief 时 MLP 是应优先验证的 baseline。

总计本地 fast + perception + belief + world ensemble + gate/value 约 **20M–23M 参数**（按实现变化），慢 VLM 单独计算 4B–8B。参数量不等于计算预算：视觉 backbone、候选数、重规划频率和多步模拟通常更影响延迟。

## 5. 正向计算：如何评价“使用 fast”

模式 `o` 是一个带终止条件的闭环选项 `o=(I_o, π_o, β_o)`。FAST 选项可能持续 0.5 s 或直到子目标到达；PLAN 包含等待与规划后执行；RECOVER 直到安全集到达或超时。以 50 ms 为原子步，选项时长为 `k` 步，实际用观测到的 `k`。[Options 原论文](https://people.eecs.berkeley.edu/~russell/classes/cs294/f05/papers/sutton%2Bal-1999.pdf)

对候选 fast option 做世界模型反事实：

1. `b̂_0 = b_t`。
2. 对 `j=0…H−1`：`Û_j=π_θ(b̂_j,g)`，取第一步 `ũ_j=Û_j[0]`。
3. 运行部署同构的安全过滤器：`û_j = S(D(b̂_j),ũ_j)`。
4. `b̂_(j+1) ~ F_ψ^m(b̂_j,û_j,Δt)`，得到 `r̂_j, p̂_fail,j, p̂_term,j`。
5. 聚合 rollout return，并对 ensemble 均值/方差及 failure 做保守校正。

也就是预测 `F` 所描述的原子物理状态演化，动作由 **被评价的 policy** 在预测状态上闭环产生；不能只给 `mode=VLA` 这个 token，就假定模型理解未来 VLA 的所有动作。若直接学习 `P(b',k,R | b,o)`，它就是 option model，只对数据中的固定 option 版本有定义；policy 更新后必须重训练/重新标定。仅有混合日志且没有选项覆盖，无法从相关性中识别“换用另一个 policy”的结果。

每个 ensemble 成员/粒子得到

`G_m = Σ_(j=0)^(H−1) γ^j r̂_j + γ^H (1−d̂_H)V̄(b̂_H,g)`。

规划评分可用 `J=mean_m(G_m)−κ·std_m(G_m)−λ_risk·p̂_fail−λ_latency·T_compute`，或使用返回分布的下分位数/CVaR。bootstrap ensemble 分歧不是校准后的失败概率；`κ`、阈值和 failure head 要在 held-out 真实数据标定。无数据的地方不能因为成员一致就认为安全。用多个模型减少方差不消除共享的错误。

短时模型从真实 replay 的状态分支，比长链想象稳健；这一点由 MBPO 的模型误差分析与短 rollout 设计支持，不意味着固定任务不会发生模型利用。[MBPO 原论文](https://arxiv.org/abs/1906.08253) 不确定性 ensemble 和采样传播可参考 PETS。[PETS 原论文](https://arxiv.org/abs/1805.12114)

## 6. Gate 奖励与 SMDP 训练

在每个原子步定义外部任务奖励，示例为：`r=+1·success −1·terminal_failure −0.001·每50ms −c_force·超限量 −c_collision·碰撞`。这些值只表示量纲和相对关系；先规定成功/损坏/超时的操作性定义，再用 Pareto 曲线选择权重。真实硬件硬约束用 shield/停止保证在可证范围内，不能用“大罚分”代替。

如果想优先 fast，表达为真实资源成本：`−c_compute·GPU秒 −c_time·墙钟秒`；slow 等待时的环境状态、奖励和风险都要计入。固定每次 fast 调用 `+0.1` 会诱导频繁切换、空调用或不完成任务而刷调用奖励，且改变任务最优解。若业务真的愿意牺牲任务质量换算力，这是多目标定义，应明确写出，而不是假装奖励无副作用。

选项级奖励 `R_t^(o)=Σ_(j=0)^(k−1)γ^j r_(t+j)−c_call(o)`，目标

`y_t = R_t^(o) + γ^k (1−d_(t+k)) max_(o'∈可用选项) Q̄(b_(t+k),g,o')`，

`L_gate = E[(Q_η(b_t,g,o_t)−stopgrad(y_t))²]`。

如果 `γ` 对应单位墙钟而不是控制步，则用 `exp(−ρ τ)`，并将奖励在真实持续时间积分。不能所有选项统一只乘一次 `γ`，因为慢思考用时不同。计划计算期间只 hold 也要记录成实际时间和转移。

需要密集 shaping 时可用 `r'=r+γΦ(b_(t+1))−Φ(b_t)`；终止态潜能置零并保持奖励/折扣定义一致。SMDP 选项聚合后的 shaping 为 `γ^kΦ(b_(t+k))−Φ(b_t)`。潜势 shaping 的不变性条件可参考原论文；给 mode 固定 bonus 不属于该类。[Ng 等原论文](https://people.eecs.berkeley.edu/~russell/papers/icml99-shaping.pdf)

第一版不必 end-to-end RL gate：先用验证集上各选项的实际成功/代价作为监督，训练 fast-risk 分类器；或直接阈值 gate。加入 hysteresis（进 FAST 需要连续若干帧满足较严阈值、退出用稍宽阈值）和最短 dwell time；紧急停止允许越过 dwell time。否则 gate 抖动会让轨迹不连续、数据不可辨识。训练时在仿真里做同状态分支 rollout，比较 fast/plan/recover 的反事实，减少 gate 只看见自身偏好样本的选择偏差。

## 7. 反向传播与各模块训练信号

### 7.1 数据字段必须记录实际执行

每个 transition 存 `(o_t,x_t,b_t,g_t,u_raw,t,u_exec,t,r_env,t,x_(t+1),done,dt,option_id,option_duration,shield_intervention,policy_version,sim_or_real)`。world model 用 `u_exec`，否则动作被安全过滤器改写后，模型会把“未实际执行的动作”错误关联到结果。

如果策略学习 `u_raw`，应保留 raw、executed 两个字段，明确当前优化的是复合控制器 `S∘π` 还是过滤前 policy。只存过滤后的标签而让 RL critic 以过滤前动作为条件会产生 Bellman 不一致。建议初版模仿训练对可行 teacher action 做 BC，并额外惩罚被 shield 修改的幅度；RL residual 训练则明确把 shield 作为环境控制映射。

### 7.2 快策略：先蒸馏与纠错，再考虑 RL

成功 teacher 轨迹的 chunk 损失：

`L_BC = E[Σ_(h=0)^15 m_h (λ_p||Δp̂_h−Δp*_h||₁ + λ_R d_SO3(R̂_h,R*_h) + λ_g||ŵ_h−w*_h||₁)] + β_KL KL(q_φ(z|b,g,U*) || N(0,I))`。

`m_h` 屏蔽越过 episode 边界的动作；动作项按单位归一化，避免毫米和弧度直接相加。若预测旋转向量，也可在小角度区域先用归一化 L1，但论文报告中应提供 SO(3) 几何误差。CVAE latent 对应 ACT 类训练；确定性 baseline 取消 KL 与 posterior。

快策略犯错后，收集**它实际到达的状态**上的 teacher 修正标签，再混合 replay 训练，不能只不断重复理想 teacher 的成功状态。SafeDAgger 给出选择性查询专家的相关范例，但其验证来自驾驶模拟，不能直接视为机械臂保证。[SafeDAgger 原论文](https://arxiv.org/abs/1605.06450)

慢 VLM 输出只能算候选，不天然是 expert；teacher 标签要经过仿真验证或可靠操作员验证。失败轨迹不直接当正例 BC，可以用来训练 value/risk/world model，以及从失败前缀的可恢复状态重新规划。

### 7.3 世界模型：监督学习

每个模型以 bootstrap 数据拟合

`L_W^m = E[−log N(stopgrad(b_(t+1)); μ_m(b_t,u_exec,dt),diagσ²_m) + λ_x||D(μ_m)−x_(t+1)||_Huber + λ_r ℓ(r̂_m,r_env) + λ_d BCE(d̂_m,done) + λ_f BCE(p̂_fail,m,unsafe)]`。

目标 `b_(t+1)` 来自冻结/target encoder。奖励能用可观测几何与 task predicate 精确计算时，优先计算，不必另训练 reward head；contact/unsafe 对应实际传感器标签，不能拿模型自己的判断给自己做标签。增加 1、2、4 步 teacher-forced / free-running 多步验证，选 horizon 时看真实校准误差，不要只看一步均方误差。真实与仿真分布应分开评估；必要时共享 backbone + real residual dynamics，并显式给模型 domain 标志。

### 7.4 Gate、world model、policy 的梯度边界

初版交替训练：`更新 W → 冻结 W 生成短 rollout / labels → 更新 Q/gate → 更新 fast BC`；部署版本固定。规划评分、模型生成的标签和 target Q 全部 stop-gradient，不让 gate 通过修改模型“证明自己做对了”。离散选项用 Q-learning、策略梯度或监督训练，不需要为 argmax 人造可微梯度。

这**不是**说所有 world-model RL 都必须阻断动力学对动作的导数。若后期采用可微模型优化 actor，可以冻结 `ψ` 的参数梯度，但允许 `∂F/∂u · ∂u/∂θ` 流向 actor；这条路径非常容易利用模型误差，且 shield/接触经常不可微，应与纯真实/仿真 RL 做对照。安全起步版不依赖它。

## 8. Pick-place 到长程任务：不要让 GRU 代替任务记忆

对于 pick-place，显式阶段可以是 `approach → align → grasp → lift → transport → release → verify`。每个阶段有 initiation set、成功谓词、超时、恢复边和禁止条件。对于 RoboDojo 类多分钟任务，加入**任务图/技能图 + 独立进度验证器 + 持久 episodic memory**；256 维 GRU 只承担局部运动历史，不应被宣称已经解决长程信用分配。

决策状态拓展成 `s̃_t=(b_t,c_t,M_t)`：`c_t` 是当前任务图节点/已完成谓词，`M_t` 是持久事件记录。slow 输入检索 `Retrieve(M_t,b_t,c_t)`；fast 使用当前子目标 `g(c_t)` 与局部信念。真实状态更新：

`y_t=Verify(x_(t−w:t), images, force)`，

`c_(t+1)=δ(c_t,y_t)`，

`M_(t+1)=Append(M_t,{timestamp,c_t,goal,outcome,evidence,policy_version})`。

例如 grasp 成功不能只用“夹爪已经闭合”判断；至少要验证物体跟随抬升或夹持力/宽度一致性。place 成功验证物体落在目标区域并保持一定时间，且夹爪已释放。验证器最好依赖几何/传感器证据，并报告 unknown；把 VLM 的“看上去成功”设为唯一 verifier 会让 gate、奖励与自我评价形成同一错误闭环。

预测局部 closed-loop option 时，WAM 只预测 `b`；已确定的任务节点 `c` 在当前选项内保持固定，或通过同一 verifier 的近似更新。在没有验证好 `c` 切换模型时，不应让 latent dynamics 凭空想象任务图跨节点完成。长程规划通过技能级/选项级转移模型和可观测成功事件连接，不依赖像素世界模型连推几千步。

SayCan 展示了用 skill value/affordance 约束语言模型提议的思路；对本方案的启示是，语义上合理与本机器人当前能做成必须由不同来源证据检查。[SayCan 原论文](https://arxiv.org/abs/2204.01691) Inner Monologue 展示成功反馈与场景反馈对闭环高层规划的作用；这里可转成 verifier 事件驱动的重规划。[Inner Monologue 原论文](https://arxiv.org/abs/2207.05608)

若一个长程回合包含 `N` 个技能，即使每个技能独立成功概率均为 `p`，无恢复整回合成功概率也为 `p^N`。例如 `p=0.99,N=50` 时只有约 60.5%。真实相关失败可能更复杂，所以训练恢复策略、避免重复不可逆错误、独立验证进展通常比把一个小模型换成更大的模型更重要。恢复后继续完成的回合成功率须与首次尝试成功率分别报告。

### 对主报告候选数值架构的具体审查

若采用 `p36=q7+dq7+tcp6+gripper1+wrench6+prev_u7+image_age2`，维度正好 36；tcp6 使用位置+旋转向量，仅局部适用并需避免绝对姿态的 π 附近不连续。两相机 ResNet pooled 各 512 维时拼接共 1,024 维，加 p36 为 1,060，而不是 640。若要 `fusion640→512→256`，应画出两相机各 `512→256` 的 projection，与 `p36→128` 的 projection，形成 `256+256+128=640`；如果再拼 goal 或 task progress，也要重新核对维度。

ResNet-18 约 11.7M 是带 1,000 类分类头的常用总数，去头用于特征提取约 11.2M。8 层、hidden256、FFN1024、self+cross attention 的 actor 约 8.4M（加 embedding/head 后约 8.5–9M），与主稿的预算相容。本独立稿使用 4 层约 4.2M 作为更小 baseline。

`H16,K2–4` 等于每次 100–200 ms 开环执行，建议只在非接触、宽裕碰撞距离或高速推理做不到的区域使用；接触/抓取/释放附近用 `K1`，低层 500 Hz 并不能恢复 200 ms 未重新观测造成的视觉盲区。world input263=b256+action7 适合固定 20 Hz 且把等待每tick记录的方案；实际有可变时延时加 dt 为264维或显式建模延迟/动作队列。

`u_exec` 在本文指经过 shield、发送给固定低层控制器的命令，**不是事后测到的真实末端位移**。命令未实现、饱和与通信延迟正是动力学要学习的部分；把实现后的位移当作动作会造成后验信息泄漏。模型若在末端目标层学习，应固定同一低层控制器版本并记录饱和/时延；若低层版本变化，重新建模或作为条件输入。日志还应另存真实关节/执行器反馈，便于辨识。

## 9. 训练顺序、对照与可证伪点

1. 完成标定、碰撞模型、真实成功判据与低层轨迹接口；记录实际延迟分布。用 scripted state machine + impedance/IK 完成任务，作为必须打败的基线。
2. 仿真做主动系统辨识与扰动采样：仅固定布局，不固定质量、摩擦、相机误差、时延与接触参数。让随机化范围由测量决定。固定场景不等于可以删除 domain randomization；其主要价值是覆盖实际重复操作误差，而不只是跨场景泛化。[Domain Randomization 原论文](https://arxiv.org/abs/1703.06907)
3. 使用仿真 oracle/script/MPC 生成起始 teacher（例如 50–200 条成功轨迹作首轮量级假设，训练数据需求必须画 scaling curve）。训练小 fast policy。先评估“无 VLM、无 gate、无 WAM”的模型。
4. 加 selective teacher 查询与可恢复状态的数据；加入人工故障库、接触/遮挡和延迟扰动，评估 gate 的错误放行率与拒绝率。
5. 加入 WAM 候选重排，比较相同算力、相同真实数据预算下是否减少交互或失败。真值模拟器可用时，WAM 应与直接 sim rollout 比。
6. 先进行低速实物标定与保守运行，冻结核心策略，只更新在线状态/隐变量；积累真实 replay 后做离线/影子 residual 或 policy 微调，再锁定新版本验证。RMA 说明“在线适应”可以通过历史推断隐变量而不改网络权重，但它是腿式运动证据，迁移到接触操作仍需实验。[RMA 原论文](https://arxiv.org/abs/2107.04034)
7. 完整 factorial 消融：脚本控制；fast BC；fast+纠错；fast+gate+慢 planner；前项+WAM；再加 RL residual。若系统最后几乎不需要慢 VLM，应如实报告，不能为了叙事保留无增益模块。

必须分别报告：单次尝试成功率、含自动恢复的整回合成功率、条件接受成功率、拒绝率、平均与 p99 完成时间、每回合 VLM 调用次数、shield 干预率、重置成本与人工干预率。允许拒绝会提高条件成功率，却未必提高无人干预产能，不能混淆分母。仿真数据和真实数据分别计量。

若目标只是一项严格固定的短任务，状态机 + 几何规划 + 力控 + 少量 residual 往往是强基线。慢 VLM 的可检验优势是减少人手写规则、处理定义好的异常、提议新的可验证子目标；不能预设它比任务脚本更可靠。RT-H 的语言动作层级支持把语义和低层控制解耦的思路，但对固定单任务，语言层的样本共享优势可能很小。[RT-H 原论文](https://arxiv.org/abs/2403.01823)
